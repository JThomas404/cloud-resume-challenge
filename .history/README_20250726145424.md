# AWS Cloud Resume Challenge - Cloud engineering and DevOps Portfolio Project

A comprehensive cloud engineering project demonstrating proficiency in AWS services, Infrastructure as Code, and DevOps practices. This project showcases practical skills in serverless architecture, CI/CD automation, and cloud security.

**Project Reference Repo**: https://cloudresumechallenge.dev/docs/the-challenge/aws/

## Executive Summary

Built and deployed a full-stack serverless application using AWS cloud services, implementing industry best practices for scalability, security, and automation. The project demonstrates end-to-end cloud engineering capabilities from infrastructure provisioning to continuous deployment.

### Key Achievements

1. **Serverless Web Application**: Developed a responsive portfolio website with dynamic visitor counter functionality
2. **AWS Cloud Infrastructure**: Architected scalable infrastructure using S3, CloudFront, Lambda, and DynamoDB
3. **DevOps Automation**: Implemented CI/CD pipeline with GitHub Actions for automated testing and deployment
4. **Infrastructure as Code**: Managed all resources using Terraform for consistent, repeatable deployments
